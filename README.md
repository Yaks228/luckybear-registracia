## 🔧 Управление Ссылками

Все ссылки на сайте управляются через файл `link.json`. Это позволяет:

- Быстро обновлять ссылки без редактирования HTML
- Централизованно управлять всеми URL
- Легко добавлять новые ссылки и разделы
- Поддерживать актуальность зеркал

### Примеры использования:

```json
{
  "navigation": {
    "home": "#home",
    "registration": "#registration"
  },
  "external": {
    "mirror_1": "https://luckybear-mirror1.ru",
    "telegram": "https://t.me/luckybear_official"
  }
}
```

## 🎨 Кастомизация

### Изменение цветов
Редактируйте CSS переменные в `styles.css`:

```css
:root {
  --color-primary: #1a1a1a;
  --color-accent: #1e40af;
  --color-white: #ffffff;
  /* ... другие переменные */
}
```

### Изменение шрифтов
Добавьте новые шрифты в папку `font/` и обновите `@font-face` правила в `styles.css`

### Обновление контента
- SEO-тексты: В `index.html` в соответствующих секциях
- Ссылки: В `link.json` файле
- Изображения: Замените `logo.svg` и `logo.png`
